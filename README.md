## 📋 Tentang Proyek
**Tsubasa Arena** adalah platform booking lapangan futsal yang memudahkan customer untuk:
- Melihat daftar lapangan yang tersedia
- Booking lapangan dengan memilih tanggal, jam, dan durasi
- Upload bukti pembayaran
- Melihat riwayat booking sendiri
  
**Untuk admin**, website ini menyediakan:
- Dashboard statistik (total lapangan, user, booking, pendapatan)
- Kelola lapangan (tambah, edit, hapus, upload gambar)
- Kelola booking (konfirmasi, batalkan, selesaikan, filter status)
- Kelola user (aktifkan, nonaktifkan, hapus)
- Laporan statistik (lapangan populer, booking per hari, per bulan)
  
## 🛠️ Teknologi
Proyek ini menggunakan teknologi berikut:
- **PHP** :untuk logika backend dan koneksi database
- **MySQL** :untuk menyimpan data lapangan, booking, user, dll
- **HTML & CSS** :untuk struktur dan tampilan website
- **JavaScript** :untuk interaktif (CAPTCHA AJAX, preview gambar, dll)
- **XAMPP** :sebagai local server (Apache + MySQL)

## 🔧 Fitur Lengkap
**Untuk Customer:**
- Registrasi akun baru
- Login dengan username dan password (dilengkapi CAPTCHA)
- Lihat daftar lapangan dengan pagination (6 lapangan per halaman)
- Detail lapangan (info lengkap + peta lokasi + form booking)
- Booking lapangan (pilih tanggal, jam, durasi, upload bukti transfer)
- Riwayat booking (lihat semua booking, batalkan jika masih pending)
- Upload bukti pembayaran

**Untuk Admin:**
- Login khusus admin (username + password + CAPTCHA)
- Dashboard statistik ringkasan
- Kelola lapangan (CRUD + upload gambar + pagination 5 data per halaman)
- Kelola booking (lihat semua, filter status, pagination, konfirmasi, batalkan, selesaikan)
- Kelola user (lihat daftar, aktifkan/nonaktifkan, hapus, pencarian)
- Halaman statistik lengkap (grafik lapangan populer, booking per hari, per bulan)
